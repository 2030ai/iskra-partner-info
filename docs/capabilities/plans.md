# Планы

Статус: `available`

Дата обновления: 2026-09-07

## Коротко

«Планы» — внутренний рабочий раздел Искры для задач, событий, напоминаний и
повторяющихся действий. Он заменяет прежний раздел «Расписание».

## Какие задачи клиента закрывает

- собирает личные задачи и события в одном месте;
- помогает не пропускать сроки и повторяющиеся действия;
- позволяет запускать AI-агента по плану с нужными материалами и навыками;
- поддерживает командную работу через назначения и участников событий.

## Что входит

- список задач, календарь и сводка ближайших действий;
- задачи со сроком, проектом, часовым поясом, повторением и напоминанием;
- события с началом, окончанием, участниками, повторением и напоминанием;
- назначение задачи коллеге владельцем или администратором организации;
- действие без автоматизации, уведомление или запуск AI-агента;
- создание задач и событий из чата, в том числе голосом в поддерживаемом
  мобильном режиме;
- перенос ранее созданных задач из раздела «Расписание».

## Синхронизация с внешними календарями

В Искре 2.63 там, где синхронизация включена администратором, раздел
«Настройки → Календари и задачи» подключает Яндекс, Mail.ru, iCloud, Google,
Exchange Server и другие CalDAV-серверы. Подключения отдельные для каждого
активного профиля. События обмениваются в обе стороны; задачи — только там,
где их поддерживает провайдер. Google синхронизирует события, но не задачи.

Для Google требуется настроенный вход через Google; первичное подключение
выполняется в веб-версии с компьютера. Exchange Server требует доступного
HTTPS-адреса EWS; Microsoft 365 для этой синхронизации не поддерживается.
Доступные поля, повторения и напоминания зависят от провайдера.

Удаление, отмена или отклонение связанной записи в Искре может удалить её
во внешнем календаре; Exchange при этом может разослать приглашённым отмену.
Отключение самого подключения не удаляет записи во внешнем календаре.
Календари с правом только чтения не принимают изменения из Искры.

## Как объяснять клиенту

«Планы» находятся внутри Искры и управляют её задачами, событиями и агентскими
запусками. Их встроенная синхронизация поддерживает постоянный обмен с внешними
календарями. Навык «Календарь» выполняет отдельные действия по запросу в чате;
эти возможности не следует называть взаимозаменяемыми.

## Ограничения и условия

- доступность отдельных действий зависит от тарифа, роли и конфигурации;
- AI-запуск расходует доступный пакет, обычные задачи и напоминания сами по себе
  не требуют AI-запуска;
- агент действует в пределах прав, подключённых папок Памяти и настроек навыков;
- точные лимиты задач, повторений и запусков зависят от конфигурации контура;
- внешняя синхронизация требует включённого компонента, личного подключения
  в выбранном профиле, необходимых прав и сетевого доступа; обмен не охватывает
  всё далёкое прошлое и будущее календаря.
