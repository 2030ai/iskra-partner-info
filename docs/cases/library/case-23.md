# Кейс 23. Исходные показатели → проект стратегии и дорожной карты

**Расчётный потенциал: ≈52 часов в год при указанном ниже объёме работы.**

**Пользователь:** стратегический отдел, администрация, руководство компании.

## Какая работа занимает время

Стратегический документ требует собрать показатели, описать сильные стороны и ограничения, согласовать цели между разделами и оформить дорожную карту. Большая часть подготовки — сведение уже имеющихся материалов.

## Как использовать Искру

Сотрудник передаёт Искре проверенные показатели, действующие планы, ограничения, заданные цели и структуру стратегии. Результат работы:

- Проект разделов стратегии с источниками.
- Карта проблем и вариантов действий.
- Таблица целей, показателей и мероприятий.
- Противоречия и вопросы для стратегической сессии.

Сотрудник проверяет результат и принимает окончательное решение. Стратегию, прогнозные предпосылки и приоритеты принимает руководство. Обсуждения, согласования и реализация мероприятий считаются отдельно.

**Пример задачи:** «Собери проект стратегии по материалам. Свяжи каждую цель с исходной проблемой и показателем. Предложи варианты мероприятий и вынеси неподтверждённые допущения на обсуждение».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Комплектов за год | 1 |
| Единица работы | один проект стратегии |
| Ручная работа на единицу | 3 360 мин |
| Работа с Искрой, включая проверку | 240 мин |
| Экономия на единицу | **3 120 мин** |

**1 × (3 360 − 240) / 60 ≈ 52 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
