# Кейс 31. Техническое задание → замечания до согласования

**Расчётный потенциал: ≈150 часов в год при указанном ниже объёме работы.**

**Пользователь:** закупочная служба, технический заказчик, руководитель проекта.

## Какая работа занимает время

Несколько участников согласования находят одни и те же пропуски и противоречия в техническом задании. Документ возвращается на доработку, а очередная версия проходит круг заново.

## Как использовать Искру

Сотрудник передаёт Искре проект ТЗ, утверждённые требования, шаблон и чек-листы согласующих. Результат работы:

- Проверка комплектности разделов.
- Противоречия в характеристиках, объёмах и сроках.
- Список неоднозначных критериев приёмки.
- Проект правок и вопросов заказчику.

Сотрудник проверяет результат и принимает окончательное решение. Каждый согласующий сохраняет свою ответственность. Искра не гарантирует отсутствие нарушений; актуальные требования задаются проверенной базой клиента.

**Пример задачи:** «Проверь ТЗ до согласования по нашим чек-листам. Найди противоречия требований и неясные критерии приёмки. Для каждого замечания предложи уточнение и укажи место в документе».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| ТЗ за год | 200 |
| Проверяющих на одно ТЗ | 3 |
| Единица работы | проверка одним специалистом |
| Ручная работа на единицу | 30 мин |
| Работа с Искрой, включая проверку | 15 мин |
| Экономия на единицу | **15 мин** |

**200 × 3 × (30 − 15) / 60 ≈ 150 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
