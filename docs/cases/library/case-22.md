# Кейс 22. Две версии реестра → изменения, сегменты и аналитика

**Расчётный потенциал: ≈87 часов в год при указанном ниже объёме работы.**

**Пользователь:** аналитическая служба, управление развитием, бизнес-ассоциация.

## Какая работа занимает время

Из реестра нужно выделить новые и выбывшие записи, изменения состава по территориям или отраслям и подготовить отчёт. Ручные фильтры и перенос строк приходится повторять после каждого обновления.

## Как использовать Искру

Сотрудник передаёт Искре две выгрузки реестра, устойчивые идентификаторы и справочники сегментов. Результат работы:

- Списки добавленных, выбывших и изменённых записей.
- Динамика по территориям и сегментам.
- Проверка дублей и неоднозначных совпадений.
- Аналитическая записка и графики изменений.

Сотрудник проверяет результат и принимает окончательное решение. Ответственный проверяет изменения. При отсутствии стабильного идентификатора совпадения требуют ручного подтверждения.

**Пример задачи:** «Сравни выгрузки по идентификаторам. Покажи новые, выбывшие и изменённые записи, сгруппируй динамику по сегментам и собери отчёт с контрольными суммами».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Обновлений за год | 12 |
| Единица работы | одно обновление |
| Ручная работа на единицу | 480 мин |
| Работа с Искрой, включая проверку | 45 мин |
| Экономия на единицу | **435 мин** |

**12 × (480 − 45) / 60 ≈ 87 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
