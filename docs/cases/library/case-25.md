# Кейс 25. Измерения и сводки → экологический отчёт

**Расчётный потенциал: ≈63 часа в год при указанном ниже объёме работы.**

**Пользователь:** экологическая служба, производственный контроль, территориальный аналитик.

## Какая работа занимает время

Данные мониторинга нужно собрать из таблиц и публикаций, привести к сопоставимым единицам, показать динамику и оформить отчёт. Одни и те же графики вручную переносятся в несколько форматов.

## Как использовать Искру

Сотрудник передаёт Искре результаты измерений, описания методик, сопоставимые периоды и шаблон отчёта. Результат работы:

- Таблица наблюдений с единицами и источниками.
- Графики динамики и отмеченные пропуски.
- Список отклонений по предоставленным критериям.
- Проект отчёта и презентации.

Сотрудник проверяет результат и принимает окончательное решение. Эколог проверяет методику и выводы. Искра обрабатывает доступные измерения; инструментальные измерения и официальное заключение остаются профильной службе.

**Пример задачи:** «Подготовь экологический отчёт: проверь единицы и сопоставимость наблюдений, покажи динамику и пропуски. Пороговые значения используй из приложенной методики».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Отчётов за год | 12 |
| Единица работы | один комплект |
| Ручная работа на единицу | 360 мин |
| Работа с Искрой, включая проверку | 45 мин |
| Экономия на единицу | **315 мин** |

**12 × (360 − 45) / 60 ≈ 63 часа в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
