# Кейс 48. Две версии сайта → список отсутствующих переводов

**Расчётный потенциал: ≈40 часов в год при указанном ниже объёме работы.**

**Пользователь:** пресс-служба, редактор сайта, контент-менеджер.

## Какая работа занимает время

Публикации в разных языковых версиях появляются не одновременно. Редактор вручную открывает страницы, ищет соответствия и составляет список материалов, которые нужно перевести или обновить.

## Как использовать Искру

Сотрудник передаёт Искре выгрузки публикаций либо доступные разделы сайта, правила соответствия версий и период проверки. Результат работы:

- Сопоставление публикаций двух версий.
- Список отсутствующих и устаревших переводов.
- Ссылки и даты для редактора.
- Проект отчёта по полноте публикаций.

Сотрудник проверяет результат и принимает окончательное решение. Редактор подтверждает список и организует перевод. Доступ к сайту и запуск по расписанию настраиваются отдельно; качество самого перевода оценивается в другом процессе.

**Пример задачи:** «Сравни языковые версии за период. Найди публикации без соответствия, покажи ссылки и даты. Неуверенные пары вынеси на ручную проверку».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Проверок за год | 48 |
| Единица работы | одна проверка |
| Ручная работа на единицу | 60 мин |
| Работа с Искрой, включая проверку | 10 мин |
| Экономия на единицу | **50 мин** |

**48 × (60 − 10) / 60 ≈ 40 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
