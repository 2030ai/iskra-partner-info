# Кейс 54. Открытые данные компаний → профили контрагентов и инвесторов

**Расчётный потенциал: ≈264 часов в год при указанном ниже объёме работы.**

**Пользователь:** развитие бизнеса, закупки, инвестиционный офис.

## Какая работа занимает время

Перед переговорами нужно собрать сведения о компании из нескольких источников, сопоставить юридические лица, понять профиль деятельности и подготовить вопросы. Ручной поиск повторяется для каждого кандидата.

## Как использовать Искру

Сотрудник передаёт Искре список компаний, доступные проверяемые источники, критерии отбора и шаблон профиля. Результат работы:

- Профиль компании с датами и источниками.
- Разделение бренда, группы и отдельных юридических лиц.
- Сопоставление кандидатов по заданным критериям.
- Вопросы для переговоров и сведения, требующие подтверждения.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник проверяет профиль и принимает решение о переговорах. Платные базы и закрытые сведения требуют доступа; оценка не является гарантией надёжности компании.

**Пример задачи:** «Подготовь профили кандидатов по шаблону. Раздели данные юридических лиц и группы, укажи источники и даты, сравни по нашим критериям и составь вопросы для встречи».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Профилей за год | 24 |
| Единица работы | один аналитический профиль |
| Ручная работа на единицу | 720 мин |
| Работа с Искрой, включая проверку | 60 мин |
| Экономия на единицу | **660 мин** |

**24 × (720 − 60) / 60 ≈ 264 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
