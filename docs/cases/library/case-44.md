# Кейс 44. Ежедневный поток новостей → приоритетный дайджест

**Расчётный потенциал: ≈715 часов в год при указанном ниже объёме работы.**

**Пользователь:** пресс-служба, аналитический отдел, помощник руководителя.

## Какая работа занимает время

Каждый день нужно открыть десятки источников, убрать повторы, выбрать значимые события и оформить короткий обзор. Большая часть времени уходит на просмотр, а не на оценку последствий.

## Как использовать Искру

Сотрудник передаёт Искре доступные источники, тематические приоритеты, критерии отбора и шаблон дайджеста. Результат работы:

- Короткая подборка значимых публикаций.
- Объединение повторов одной новости.
- Аннотации с датами и ссылками.
- Список тем для углублённого анализа.

Сотрудник проверяет результат и принимает окончательное решение. Редактор проверяет факты и утверждает подборку. Регулярный сбор зависит от доступности источников и настройки навыка; автоматическая публикация — отдельное согласованное действие.

**Пример задачи:** «Подготовь дайджест по нашим приоритетам. Объедини повторы, укажи дату и первоисточник, кратко объясни значимость каждого события. Неподтверждённые сообщения выдели отдельно».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Рабочих дней | 220 |
| Единица работы | один дневной дайджест |
| Ручная работа на единицу | 240 мин |
| Работа с Искрой, включая проверку | 45 мин |
| Экономия на единицу | **195 мин** |

**220 × (240 − 45) / 60 ≈ 715 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
