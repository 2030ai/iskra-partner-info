# Кейс 37. Реестр задолженности → расчёт и проекты претензий

**Расчётный потенциал: ≈18 часов в год при указанном ниже объёме работы.**

**Пользователь:** финансовая служба, договорной отдел, управление имуществом.

## Какая работа занимает время

По каждому пакету задолженности нужно проверить реквизиты, рассчитать суммы по периодам, заполнить претензии и обновить реестр. При повторных расчётах легко потерять связь с договором и исходными данными.

## Как использовать Искру

Сотрудник передаёт Искре реестр задолженности, договорные условия, проверенные ставки по периодам и шаблон претензии. Результат работы:

- Расчёт задолженности и начислений с формулами.
- Проекты претензий по шаблону.
- Проверка реквизитов и отсутствующих условий.
- Обновлённая рабочая таблица для согласования.

Сотрудник проверяет результат и принимает окончательное решение. Юрист проверяет применимость ставок и оснований; сотрудник утверждает отправку. Время ожидания оплаты и сумма взыскания не включены в экономию труда.

**Пример задачи:** «Подготовь проекты претензий по реестру. Покажи расчёт по периодам и формулам из условий договора. Реквизиты и основания, которые требуют подтверждения, выдели отдельно».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Пакетов за год | 12 |
| Единица работы | один небольшой пакет претензий |
| Ручная работа на единицу | 120 мин |
| Работа с Искрой, включая проверку | 30 мин |
| Экономия на единицу | **90 мин** |

**12 × (120 − 30) / 60 ≈ 18 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
