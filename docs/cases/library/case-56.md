# Кейс 56. Анкеты подразделений → оценка зрелости и план улучшений

**Расчётный потенциал: ≈48 часов в год при указанном ниже объёме работы.**

**Пользователь:** руководитель цифровизации, организационное развитие, управляющая компания.

## Какая работа занимает время

Ответы подразделений трудно сравнивать: используются разные шкалы и неодинаковые подтверждения. Аналитик вручную проверяет анкеты, считает баллы и формулирует приоритеты улучшений.

## Как использовать Искру

Сотрудник передаёт Искре анкеты, доказательные материалы, утверждённую шкалу оценки и правила весов. Результат работы:

- Оценка по каждому критерию с подтверждением.
- Пропуски и противоречия в ответах.
- Сравнение подразделений и разрывов.
- Проект дорожной карты с приоритетами для обсуждения.

Сотрудник проверяет результат и принимает окончательное решение. Команда утверждает шкалу и приоритеты. Это инструмент подготовки оценки; оценки не должны опираться на неподтверждённые ответы или автоматически определять кадровые решения.

**Пример задачи:** «Оцени анкеты строго по переданной шкале. Для каждого балла укажи подтверждение, выдели недостающие сведения и подготовь варианты плана улучшений».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Циклов оценки за год | 4 |
| Единица работы | один цикл оценки группы подразделений |
| Ручная работа на единицу | 960 мин |
| Работа с Искрой, включая проверку | 240 мин |
| Экономия на единицу | **720 мин** |

**4 × (960 − 240) / 60 ≈ 48 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
