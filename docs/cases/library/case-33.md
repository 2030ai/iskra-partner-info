# Кейс 33. Предложения поставщиков → сравнение и записка для выбора

**Расчётный потенциал: ≈108 часов в год при указанном ниже объёме работы.**

**Пользователь:** снабжение, технический заказчик, закупочная служба.

## Какая работа занимает время

Предложения приходят в разных форматах: цены, комплектация, доставка и гарантии описаны по-разному. Специалист переносит их в общую таблицу и выясняет, что именно включено в каждую цену.

## Как использовать Искру

Сотрудник передаёт Искре предложения поставщиков, требования, правила сравнения цен и шаблон ведомости. Результат работы:

- Единая сравнительная таблица характеристик и условий.
- Отклонения от требований со ссылками на документы.
- Вопросы по отсутствующим условиям.
- Проект записки для согласования.

Сотрудник проверяет результат и принимает окончательное решение. Выбор поставщика остаётся за ответственными специалистами. Несколько предложений в одном пакете считаются одной операцией, а не отдельной экономией на каждый файл. Отраслевой вариант для электросетей: сопоставить мощность и напряжение оборудования, марку, сечение и длину кабеля с закупочной спецификацией; технический заказчик подтверждает допустимость замен.

**Пример задачи:** «Сравни предложения с требованиями. Покажи состав цены, комплектацию, сроки и гарантии. Для каждого значения укажи источник, подготовь вопросы и записку для согласования».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Пакетов в неделю на специалиста | 3 |
| Рабочих недель | 48 |
| Единица работы | один пакет сравнения |
| Ручная работа на единицу | 75 мин |
| Работа с Искрой, включая проверку | 30 мин |
| Экономия на единицу | **45 мин** |

**3 × 48 × (75 − 30) / 60 ≈ 108 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
