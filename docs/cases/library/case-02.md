# Кейс 2. Входящий запрос → маршрут исполнителю и проекты писем

**Расчётный потенциал: ≈166,7 часа в год при указанном ниже объёме работы.**

**Пользователь:** клиентский сервис, служба обращений, распределённая организация.

## Какая работа занимает время

Запрос поступает в общий адрес, а сотрудник вручную определяет компетенцию подразделения, разбирает адрес и приложения, готовит сопроводительное письмо и уведомляет заявителя. Ошибочная маршрутизация добавляет повторную работу.

## Как использовать Искру

Сотрудник передаёт Искре запросы, справочник подразделений и территорий, правила компетенции и шаблоны двух писем. Результат работы:

- Тема и краткое содержание каждого запроса.
- Предлагаемый исполнитель с основанием выбора.
- Проекты сопроводительного письма и уведомления заявителю.
- Очередь неоднозначных запросов для ручного решения.

Сотрудник проверяет результат и принимает окончательное решение. Отправку и окончательный выбор исполнителя подтверждает сотрудник. Автоматический приём запросов требует подключения каналов поступления.

**Пример задачи:** «Распредели запросы по приложенному справочнику компетенций. Покажи основание маршрута и подготовь два проекта письма. Неоднозначные адреса выдели для проверки».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Запросов за год | 500 |
| Единица работы | один запрос |
| Ручная работа на единицу | 25 мин |
| Работа с Искрой, включая проверку | 5 мин |
| Экономия на единицу | **20 мин** |

**500 × (25 − 5) / 60 ≈ 166,7 часа в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
