# Кейс 16. Протоколы и отчёты → контроль исполнения поручений

**Расчётный потенциал: ≈80 часов в год при указанном ниже объёме работы.**

**Пользователь:** аппарат управления, проектный офис, секретариат.

## Какая работа занимает время

Поручения лежат в протоколах, а ответы — в отдельных отчётах. Чтобы подготовить статус, координатор сопоставляет формулировки, ищет доказательства исполнения и отмечает просрочки.

## Как использовать Искру

Сотрудник передаёт Искре протоколы с поручениями, отчёты исполнителей и согласованные правила статусов. Результат работы:

- Реестр поручений с подтверждающими фрагментами отчётов.
- Разделение полного, частичного и неподтверждённого исполнения.
- Список просрочек и отсутствующих ответов.
- Краткая записка руководителю.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник подтверждает итоговый статус. Отсутствие упоминания в отчёте означает отсутствие подтверждения, а не доказанное невыполнение.

**Пример задачи:** «Сопоставь поручения с отчётами. Для каждого статуса приложи подтверждение. Частично выполненное и отсутствие отчёта покажи отдельно, подготовь вопросы исполнителям».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Еженедельных проверок | 48 |
| Единица работы | одна проверка |
| Ручная работа на единицу | 120 мин |
| Работа с Искрой, включая проверку | 20 мин |
| Экономия на единицу | **100 мин** |

**48 × (120 − 20) / 60 ≈ 80 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
