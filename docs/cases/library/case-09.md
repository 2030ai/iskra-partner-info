# Кейс 9. Деловой текст → редакторская правка перед подписанием

**Расчётный потенциал: ≈183,3 часа в год при указанном ниже объёме работы.**

**Пользователь:** секретариат, редакторская служба, руководитель.

## Какая работа занимает время

Руководитель и редактор отвлекаются на опечатки, тяжёлые формулировки и разное оформление повторяющихся реквизитов. На потоке даже короткая вычитка становится заметной нагрузкой.

## Как использовать Искру

Сотрудник передаёт Искре короткие проекты писем, корпоративные правила оформления и примеры принятого стиля. Результат работы:

- Предлагаемая редакция письма.
- Список исправлений с объяснениями.
- Отдельный перечень смысловых неоднозначностей.
- Проверка наличия обязательных реквизитов.

Сотрудник проверяет результат и принимает окончательное решение. Содержательное согласование длинных и сложных документов сюда не входит. Сотрудник принимает или отклоняет каждую смысловую правку.

**Пример задачи:** «Вычитай письма по нашему стилю. Покажи исправления и отдельно вопросы, где редактура может изменить смысл. Проверь реквизиты по приложенной форме».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Коротких писем в день | 100 |
| Рабочих дней | 220 |
| Единица работы | одно короткое письмо |
| Ручная работа на единицу | 1 мин |
| Работа с Искрой, включая проверку | 0,5 мин |
| Экономия на единицу | **0,5 мин** |

**100 × 220 × (1 − 0,5) / 60 ≈ 183,3 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
