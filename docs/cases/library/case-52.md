# Кейс 52. Отчёты по объектам → единый реестр состояния и работ

**Расчётный потенциал: ≈28 часов в год при указанном ниже объёме работы.**

**Пользователь:** управление имуществом, эксплуатация, проектный офис.

## Какая работа занимает время

Подрядчики и подразделения присылают отчёты с разными названиями колонок и файлов. Нужно сопоставить их с перечнем объектов, выявить отсутствующие сведения и увидеть изменение статусов.

## Как использовать Искру

Сотрудник передаёт Искре мастер-реестр объектов, отчёты исполнителей, предыдущий срез и правила статусов. Результат работы:

- Единый реестр объектов и подтверждённых статусов.
- Изменения по сравнению с прошлым периодом.
- Список объектов без отчётов или с противоречиями.
- Проект сводки и запросов уточнений.

Сотрудник проверяет результат и принимает окончательное решение. Специалист подтверждает состояние объекта по проверенным материалам. Осмотр, инженерное заключение и выявление нарушений по спутниковым снимкам в сценарий не входят. Для ремонтной службы источниками служат план ремонтов, журнал дефектов и документы о закрытии работ. В сводке показываются повторные дефекты, просроченные работы и неподтверждённое завершение.

**Пример задачи:** «Сведи отчёты по мастер-реестру объектов. Покажи изменение статусов, отсутствующие сведения и расхождения. Подготовь сводку с источниками и вопросы исполнителям».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Циклов за год | 4 |
| Единица работы | один цикл сверки |
| Ручная работа на единицу | 480 мин |
| Работа с Искрой, включая проверку | 60 мин |
| Экономия на единицу | **420 мин** |

**4 × (480 − 60) / 60 ≈ 28 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
