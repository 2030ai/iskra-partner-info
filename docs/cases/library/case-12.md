# Кейс 12. Запрос на поддержку проекта → проверка по внешним источникам

**Расчётный потенциал: ≈229,2 часа в год при указанном ниже объёме работы.**

**Пользователь:** комплаенс, партнёрская служба, пресс-служба.

## Какая работа занимает время

Перед поддержкой проекта требуется изучить запрос, проверить заявителя по разрешённым реестрам и сопоставить содержание с правилами организации. Сотрудник повторяет поиск и оформление ответа для каждого пакета обращений.

## Как использовать Искру

Сотрудник передаёт Искре запросы, доступные актуальные реестры, согласованные правила поддержки и шаблоны ответов. Результат работы:

- Карточка заявителя со ссылками и датами проверки.
- Подтверждённые совпадения и неоднозначные результаты поиска.
- Замечания по правилам поддержки.
- Проекты ответов для согласования.

Сотрудник проверяет результат и принимает окончательное решение. Специалист подтверждает совпадения, правовую оценку и решение о поддержке. Поиск выполняется только в доступных источниках; отсутствие результата поиска не доказывает отсутствие ограничений.

**Пример задачи:** «Проверь запросы по согласованным источникам и правилам поддержки. Для совпадений укажи идентификаторы и дату проверки; неоднозначные результаты вынеси отдельно. Подготовь проекты ответов».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Пакетов за год | 50 |
| Единица работы | один пакет из 10 запросов |
| Ручная работа на единицу | 320 мин |
| Работа с Искрой, включая проверку | 45 мин |
| Экономия на единицу | **275 мин** |

**50 × (320 − 45) / 60 ≈ 229,2 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
