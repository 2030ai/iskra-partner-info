# Кейс 30. Рекомендации комиссии → аналитическая справка и варианты действий

**Расчётный потенциал: ≈286 часов в год при указанном ниже объёме работы.**

**Пользователь:** аналитический отдел, аппарат управления, проектный офис.

## Какая работа занимает время

После заседания внешней комиссии нужно понять рекомендации, сопоставить их с собственным опытом и практиками других организаций и подготовить содержательную справку руководителю.

## Как использовать Искру

Сотрудник передаёт Искре решения и рекомендации комиссии, проверенные материалы о собственной практике, доступные внешние примеры и шаблон справки. Результат работы:

- Краткое содержание рекомендаций и их основания.
- Сопоставление с действующими мерами организации.
- Сравнение релевантных практик с источниками.
- Проект справки и варианты следующих действий.

Сотрудник проверяет результат и принимает окончательное решение. Аналитик проверяет факты и формулирует окончательную позицию. Этот процесс оценивает содержание рекомендаций; формальный контроль исполнения поручений не заменяется.

**Пример задачи:** «Подготовь справку по рекомендациям комиссии: контекст, наши меры, сопоставимые практики, варианты действий. Для ключевых фактов укажи первоисточник и вопросы для проверки».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Справок за год | 52 |
| Единица работы | одна аналитическая справка |
| Ручная работа на единицу | 360 мин |
| Работа с Искрой, включая проверку | 30 мин |
| Экономия на единицу | **330 мин** |

**52 × (360 − 30) / 60 ≈ 286 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
