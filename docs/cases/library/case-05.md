# Кейс 5. Реестр обращений → темы, повторы и проблемные зоны

**Расчётный потенциал: ≈550 часов в год при указанном ниже объёме работы.**

**Пользователь:** служба качества, клиентский сервис, контактный центр.

## Какая работа занимает время

Чтобы увидеть причины повторных жалоб, специалист вручную считает обращения по темам и подразделениям, ищет дубли и собирает сводные таблицы. Из-за этого руководитель поздно замечает системную проблему.

## Как использовать Искру

Сотрудник передаёт Искре реестр обращений, справочник тем, статусы обработки и предыдущий срез. Результат работы:

- Классификация тем и группировка похожих обращений.
- Кандидаты в повторы с объяснением совпадения.
- Сводные таблицы по статусам, подразделениям и динамике.
- Краткая записка о росте нагрузки и приоритетах разбора.

Сотрудник проверяет результат и принимает окончательное решение. Регистрация отдельных обращений учитывается в другом сценарии. Здесь считается только аналитика всего реестра; она не заменяет разбор каждого обращения.

**Пример задачи:** «Проанализируй реестр: сгруппируй темы, найди возможные повторные обращения, сравни с прошлым периодом. Собери Excel и краткую записку с примерами из реестра».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Рабочих дней | 220 |
| Единица работы | один дневной реестр |
| Ручная работа на единицу | 180 мин |
| Работа с Искрой, включая проверку | 30 мин |
| Экономия на единицу | **150 мин** |

**220 × (180 − 30) / 60 ≈ 550 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
