# Кейс 40. Типовые вопросы сотрудников → ответ по базе и заявка на справку

**Расчётный потенциал: ≈288 часов в год при указанном ниже объёме работы.**

**Пользователь:** кадровая служба, внутренний сервис сотрудников.

## Какая работа занимает время

Сотрудники обращаются с повторяющимися вопросами о процедурах, отпусках и справках. Кадровик ищет правила, уточняет данные и вручную собирает заявки.

## Как использовать Искру

Сотрудник передаёт Искре согласованную кадровую базу, шаблоны заявок и разрешённые сведения конкретного сотрудника. Результат работы:

- Проект ответа со ссылкой на внутреннее правило.
- Заполненная заявка на справку или кадровую услугу.
- Сводка обращений для кадровика.
- Передача нестандартного вопроса специалисту.

Сотрудник проверяет результат и принимает окончательное решение. Персональные остатки и сведения выдаются только при проверенной авторизации и подключении источника. Без него сценарий ограничен общими правилами и подготовкой заявок; кадровое решение остаётся за специалистом.

**Пример задачи:** «Подготовь ответ сотруднику по нашей кадровой базе. Укажи источник правила, при необходимости заполни заявку. Вопросы вне базы направь кадровому специалисту».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Запросов в неделю | 30 |
| Рабочих недель | 48 |
| Единица работы | один типовой запрос |
| Ручная работа на единицу | 15 мин |
| Работа с Искрой, включая проверку | 3 мин |
| Экономия на единицу | **12 мин** |

**30 × 48 × (15 − 3) / 60 ≈ 288 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
