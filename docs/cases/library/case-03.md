# Кейс 3. Сложное обращение → обоснованный проект ответа

**Расчётный потенциал: ≈175 часов в год при указанном ниже объёме работы.**

**Пользователь:** экспертная служба, юридический отдел, консультационный центр.

## Какая работа занимает время

Для ответа приходится искать положения в регламентах, сверять редакции документов, разбирать обстоятельства и заново собирать деловой текст. Типовые вопросы повторяются, но каждый ответ должен учитывать конкретный запрос.

## Как использовать Искру

Сотрудник передаёт Искре обращение, актуальную согласованную нормативную базу, внутренние разъяснения и образцы ответов. Результат работы:

- Разбор вопросов заявителя по пунктам.
- Подборка относящихся к ним положений с источниками.
- Проект ответа в принятом стиле.
- Вопросы, для которых данных или оснований недостаточно.

Сотрудник проверяет результат и принимает окончательное решение. Юридическую позицию и отправку утверждает специалист. Это подготовка проекта, а не самостоятельное решение по обращению.

**Пример задачи:** «Подготовь проект ответа по приложенной базе. Свяжи каждый вывод с пунктом документа и его редакцией. Отдельно перечисли обстоятельства, которые нужно уточнить у заявителя».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Обращений за год | 150 |
| Единица работы | одно обращение |
| Ручная работа на единицу | 90 мин |
| Работа с Искрой, включая проверку | 20 мин |
| Экономия на единицу | **70 мин** |

**150 × (90 − 20) / 60 ≈ 175 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
