# Кейс 7. Материалы разбирательства → проект решения комиссии

**Расчётный потенциал: ≈1 200 часов в год при указанном ниже объёме работы.**

**Пользователь:** юридическая служба, комиссия по жалобам, претензионный отдел.

## Какая работа занимает время

Подготовка решения требует сопоставить доводы сторон с материалами дела и регламентом, найти похожие ситуации и оформить мотивировку. Значительная часть времени уходит на сборку повторяющейся структуры документа.

## Как использовать Искру

Сотрудник передаёт Искре материалы дела, согласованную базу правил и практики, шаблон решения. Результат работы:

- Таблица доводов, доказательств и незакрытых вопросов.
- Хронология событий с источниками.
- Проект мотивировочной и итоговой частей.
- Ссылки на документы для экспертной проверки.

Сотрудник проверяет результат и принимает окончательное решение. Комиссия рассматривает дело и принимает решение самостоятельно. Экономия относится к подготовке проекта, а не ко времени заседания.

**Пример задачи:** «Собери проект решения по шаблону. Сопоставь каждый довод с доказательствами и правилами из нашей базы. Спорные факты вынеси на рассмотрение комиссии».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Проектов решений за год | 400 |
| Единица работы | один проект решения |
| Ручная работа на единицу | 240 мин |
| Работа с Искрой, включая проверку | 60 мин |
| Экономия на единицу | **180 мин** |

**400 × (240 − 60) / 60 ≈ 1 200 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
