# Кейс 26. Отчёты средств защиты → понятная сводка по информационной безопасности

**Расчётный потенциал: ≈165 часов в год при указанном ниже объёме работы.**

**Пользователь:** служба информационной безопасности, руководитель ИТ.

## Какая работа занимает время

Результаты нескольких средств защиты приходится читать по отдельности, сопоставлять периоды и собирать в короткий доклад. Руководителю нужен общий статус и список вопросов, требующих внимания.

## Как использовать Искру

Сотрудник передаёт Искре разрешённые обезличенные выгрузки средств защиты, категории событий и шаблон суточного отчёта. Результат работы:

- Сводка событий по источникам и уровням важности.
- Динамика и необычные изменения.
- Перечень событий для проверки аналитиком.
- Проект управленческого отчёта без технического шума.

Сотрудник проверяет результат и принимает окончательное решение. Служба безопасности подтверждает классификацию и действия. Этот сценарий готовит отчёт, а не заменяет средства защиты, обнаружение атак или реагирование.

**Пример задачи:** «Сведи отчёты средств защиты в одну записку. Сверь периоды, выдели изменения относительно прошлого дня и укажи, какие выводы требуют проверки аналитиком».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Рабочих дней | 220 |
| Единица работы | одна сводка |
| Ручная работа на единицу | 60 мин |
| Работа с Искрой, включая проверку | 15 мин |
| Экономия на единицу | **45 мин** |

**220 × (60 − 15) / 60 ≈ 165 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
