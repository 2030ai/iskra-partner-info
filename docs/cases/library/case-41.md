# Кейс 41. Учётный реестр и результаты осмотра → сличительная ведомость

**Расчётный потенциал: ≈66,7 часов в год при указанном ниже объёме работы.**

**Пользователь:** бухгалтерия, служба имущества, инвентаризационная комиссия.

## Какая работа занимает время

После фактического осмотра нужно сопоставить записи с учётом, найти пропуски и дубли, перенести результаты в ведомость. Имена объектов и инвентарные номера часто записаны неодинаково.

## Как использовать Искру

Сотрудник передаёт Искре учётный реестр, фактическую опись, справочники объектов и утверждённую форму ведомости. Результат работы:

- Сопоставление записей по инвентарным номерам.
- Излишки, недостачи и неоднозначные совпадения для проверки.
- Проект сличительной ведомости.
- Реестр вопросов комиссии.

Сотрудник проверяет результат и принимает окончательное решение. Комиссия проводит осмотр, подтверждает наличие и состояние имущества и утверждает ведомость. Экономия поездок, сканеров и физической проверки в расчёт не включена.

**Пример задачи:** «Сопоставь учётный реестр и фактическую опись. Покажи расхождения и неоднозначные номера, подготовь сличительную ведомость по шаблону».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Проверяемых записей за год | 2 000 |
| Единица работы | одна запись при камеральной сверке |
| Ручная работа на единицу | 3 мин |
| Работа с Искрой, включая проверку | 1 мин |
| Экономия на единицу | **2 мин** |

**2 000 × (3 − 1) / 60 ≈ 66,7 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
