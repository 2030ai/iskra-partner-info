# Кейс 32. План закупок → предварительная группировка позиций по лотам

**Расчётный потенциал: ≈132 часа в год при указанном ниже объёме работы.**

**Пользователь:** закупочная служба, контрактный управляющий.

## Какая работа занимает время

Сотни строк нужно сопоставить с классификаторами и правилами закупки, определить допустимые группы и обосновать каждое решение. Ручная сверка особенно трудна при изменении перечней.

## Как использовать Искру

Сотрудник передаёт Искре план закупок с кодами, действующие согласованные перечни и правила группировки. Результат работы:

- Предварительная классификация каждой позиции.
- Предлагаемый состав лотов.
- Основание для каждой категории и спорные коды.
- Excel с результатом и очередью экспертной проверки.

Сотрудник проверяет результат и принимает окончательное решение. Состав лотов и применение закупочных правил утверждает специалист. Наличие кода в перечне и актуальность редакции проверяются по источникам клиента.

**Пример задачи:** «Разметь позиции по приложенным перечням и предложи лоты. Для каждой строки укажи правило и редакцию источника. Неоднозначные коды выдели для проверки закупщиком».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Планов за год | 4 |
| Единица работы | один план |
| Ручная работа на единицу | 2 100 мин |
| Работа с Искрой, включая проверку | 120 мин |
| Экономия на единицу | **1 980 мин** |

**4 × (2 100 − 120) / 60 ≈ 132 часа в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
