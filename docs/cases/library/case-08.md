# Кейс 8. Проект правового документа → проверка по чек-листу

**Расчётный потенциал: ≈247,5 часов в год при указанном ниже объёме работы.**

**Пользователь:** юридический отдел, контрольная служба, договорной отдел.

## Какая работа занимает время

Перед подписанием специалист каждый раз проверяет реквизиты, даты, основания и согласованность текста. Однотипные ошибки приходится искать в большом потоке похожих проектов.

## Как использовать Искру

Сотрудник передаёт Искре проекты документов, утверждённый чек-лист и актуальные справочные материалы. Результат работы:

- Список замечаний по каждому пункту проверки.
- Указание фрагмента документа и основания замечания.
- Выделение противоречащих друг другу реквизитов и сумм.
- Проект правок для эксперта.

Сотрудник проверяет результат и принимает окончательное решение. Правовую оценку и итоговую редакцию утверждает специалист. Проверка собственных проектов из [кейса 7](case-07.md) входит в его время и повторно не считается.

**Пример задачи:** «Проверь проекты по чек-листу. Для каждого замечания покажи фрагмент, правило и предлагаемую правку. Раздели найденные несоответствия и вопросы для юриста».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Документов в день | 9 |
| Рабочих дней | 220 |
| Единица работы | один документ |
| Ручная работа на единицу | 12,5 мин |
| Работа с Искрой, включая проверку | 5 мин |
| Экономия на единицу | **7,5 мин** |

**9 × 220 × (12,5 − 5) / 60 ≈ 247,5 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
