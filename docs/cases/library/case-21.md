# Кейс 21. План и факт → отклонения, причины и проекты запросов

**Расчётный потенциал: ≈72 часа в год при указанном ниже объёме работы.**

**Пользователь:** финансовая служба, управляющая компания, служба эксплуатации.

## Какая работа занимает время

Подразделения присылают показатели в разных таблицах. Экономист сводит данные, считает отклонения, выделяет проблемные направления и отдельно готовит запросы объяснений.

## Как использовать Искру

Сотрудник передаёт Искре плановые и фактические показатели, прошлый период, структуру подразделений и правила расчёта. Результат работы:

- Таблица исполнения плана и динамики.
- Список существенных отклонений с вкладом в общий результат.
- Разделение изменения объёмов и цен при наличии данных.
- Проекты запросов пояснений ответственным.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник проверяет расчёты и утверждает запросы. Экономия на подготовке отчёта не равна сокращению расходов на энергию или росту доходов. Для ресурсопотребления отдельно сопоставляются физический объём и стоимость: это помогает разделить влияние расхода и тарифа, не выдавая его изменение за экономию от Искры.

**Пример задачи:** «Сравни план и факт, посчитай отклонения и вклад подразделений. Подготовь вопросы по существенным изменениям. Объяснения причин формулируй как гипотезы до получения подтверждений».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Циклов за год | 12 |
| Единица работы | один цикл |
| Ручная работа на единицу | 480 мин |
| Работа с Искрой, включая проверку | 120 мин |
| Экономия на единицу | **360 мин** |

**12 × (480 − 120) / 60 ≈ 72 часа в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
