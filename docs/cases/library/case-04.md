# Кейс 4. Входящая почта → приоритеты, поручения и краткая сводка

**Расчётный потенциал: ≈640 часов в год при указанном ниже объёме работы.**

**Пользователь:** секретариат, помощник руководителя, общий почтовый ящик службы.

## Какая работа занимает время

Сотрудник перечитывает поток писем, отделяет рассылки от рабочих запросов, ищет сроки и пересылает важное коллегам. Срочные сообщения теряются среди обычной переписки.

## Как использовать Искру

Сотрудник передаёт Искре выгрузку писем либо доступное подключение к корпоративной почте, категории и правила приоритетов. Результат работы:

- Список писем по категориям и срочности.
- Краткая суть и требуемое действие по каждому рабочему письму.
- Сводка писем со сроками и вопросами без ответа.
- Предложения по распределению в папки и исполнителям.

Сотрудник проверяет результат и принимает окончательное решение. Для старта можно разобрать выгрузку. Регулярная обработка требует настройки почты; отправка, перемещение и удаление писем выполняются с необходимым подтверждением пользователя.

**Пример задачи:** «Разбери входящие по нашим категориям. Выдели письма со сроками, кратко опиши требуемое действие и собери сводку для руководителя. Перемещения предложи отдельным списком».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Писем в неделю | 200 |
| Рабочих недель | 48 |
| Единица работы | одно письмо |
| Ручная работа на единицу | 5 мин |
| Работа с Искрой, включая проверку | 1 мин |
| Экономия на единицу | **4 мин** |

**200 × 48 × (5 − 1) / 60 ≈ 640 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
