# Кейс 53. Реестр свободных объектов → инвестиционная витрина

**Расчётный потенциал: ≈78 часов в год при указанном ниже объёме работы.**

**Пользователь:** управление имуществом, инвестиционный офис, девелопер.

## Какая работа занимает время

Свободные помещения и площадки описаны неодинаково. Для встречи с инвестором приходится собирать карточки, проверять полноту данных, готовить сценарии использования и оформлять презентацию.

## Как использовать Искру

Сотрудник передаёт Искре проверенные характеристики объектов, ограничения, фотографии, условия предложения и финансовые допущения. Результат работы:

- Единые карточки объектов.
- Таблица сравнения характеристик и ограничений.
- Иллюстративные сценарии использования с отдельными допущениями.
- Проект витрины или презентации для обсуждения.

Сотрудник проверяет результат и принимает окончательное решение. Специалист утверждает характеристики и условия предложения. Оценка стоимости, техническая экспертиза и инвестиционное решение выполняются отдельно.

**Пример задачи:** «Собери витрину объектов по шаблону. Раздели подтверждённые характеристики и гипотезы использования. Для финансовых сценариев покажи исходные допущения и чувствительность».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Обновлений за год | 12 |
| Единица работы | одна небольшая витрина |
| Ручная работа на единицу | 480 мин |
| Работа с Искрой, включая проверку | 90 мин |
| Экономия на единицу | **390 мин** |

**12 × (480 − 90) / 60 ≈ 78 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
