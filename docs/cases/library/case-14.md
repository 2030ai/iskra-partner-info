# Кейс 14. Заметка руководителя → понятное поручение исполнителю

**Расчётный потенциал: ≈80 часов в год при указанном ниже объёме работы.**

**Пользователь:** помощник руководителя, координатор проектов.

## Какая работа занимает время

Короткую устную или письменную установку нужно превратить в конкретную задачу: результат, исполнитель, срок и способ приёмки. Координатор вручную оформляет и уточняет каждое поручение.

## Как использовать Искру

Сотрудник передаёт Искре заметку, справочник ролей, правила постановки задач и рабочий календарь. Результат работы:

- Проект поручения в едином формате.
- Ожидаемый результат и критерий готовности.
- Предлагаемый срок по переданным правилам.
- Список уточнений до передачи исполнителю.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник утверждает поручение и его отправку. Если поручение уже подготовлено в составе протокола, это время не прибавляется к [кейсу 13](case-13.md).

**Пример задачи:** «Оформи поручения из заметок: действие, результат, ответственный, срок, критерий приёмки. Неоднозначные назначения оставь для согласования».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Поручений в неделю | 5 |
| Рабочих недель | 48 |
| Единица работы | одно поручение |
| Ручная работа на единицу | 30 мин |
| Работа с Искрой, включая проверку | 10 мин |
| Экономия на единицу | **20 мин** |

**5 × 48 × (30 − 10) / 60 ≈ 80 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
