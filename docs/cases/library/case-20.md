# Кейс 20. Оперативные отраслевые данные → регулярная аналитическая справка

**Расчётный потенциал: ≈120 часов в год при указанном ниже объёме работы.**

**Пользователь:** производственная служба, агропредприятие, отраслевой аналитик.

## Какая работа занимает время

Еженедельные и ежемесячные отчёты повторяют одну структуру, но показатели приходится заново извлекать из документов, сравнивать и переносить в справку.

## Как использовать Искру

Сотрудник передаёт Искре оперативные отраслевые отчёты, прошлый период, словарь показателей и шаблон справки. Результат работы:

- Сопоставление объёмов и темпов по направлениям.
- Перечень отклонений и показателей с отсутствующими данными.
- Проект отраслевой справки с таблицами.
- Короткие выводы для оперативного совещания.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник проверяет отраслевые выводы. При включении этих справок в общий управленческий доклад одни и те же операции учитываются один раз.

**Пример задачи:** «Собери отраслевую справку по шаблону. Сравни показатели с прошлым периодом, укажи источники чисел и выдели вопросы, требующие комментария специалистов».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Еженедельных справок | 48 |
| Единица работы | одна еженедельная справка |
| Ручная работа на единицу | 180 мин |
| Работа с Искрой, включая проверку | 30 мин |
| Экономия на единицу | **150 мин** |

**48 × (180 − 30) / 60 ≈ 120 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
