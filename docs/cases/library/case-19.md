# Кейс 19. Новая выгрузка → актуальная справка и журнал изменений

**Расчётный потенциал: ≈192 часа в год при указанном ниже объёме работы.**

**Пользователь:** аналитическая служба, секретариат, подразделение отчётности.

## Какая работа занимает время

Справочные документы быстро устаревают. Сотрудник ищет новые значения, заменяет их по всему тексту, проверяет таблицы и форматирование, затем пытается установить, какие показатели изменились.

## Как использовать Искру

Сотрудник передаёт Искре действующую справку, новую выгрузку, соответствие полей и правила обновления. Результат работы:

- Проект обновлённой справки с сохранением структуры.
- Таблица старых и новых значений.
- Список полей без свежих данных.
- Краткий журнал изменений для проверки.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник утверждает изменения. Прямой доступ к базе данных — отдельное подключение; базовый сценарий работает с выгрузкой.

**Пример задачи:** «Обнови справку по новой выгрузке. Сохрани структуру, покажи старые и новые значения и отметь поля без подтверждённого обновления».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Обновлений в месяц | 4 |
| Месяцев | 12 |
| Единица работы | одно обновление |
| Ручная работа на единицу | 300 мин |
| Работа с Искрой, включая проверку | 60 мин |
| Экономия на единицу | **240 мин** |

**4 × 12 × (300 − 60) / 60 ≈ 192 часа в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
