# Кейс 45. Публикации по теме → аналитический обзор с источниками

**Расчётный потенциал: ≈108 часов в год при указанном ниже объёме работы.**

**Пользователь:** аналитический отдел, исследовательская команда, пресс-служба.

## Какая работа занимает время

Для тематического доклада нужно прочитать десятки публикаций, выбрать факты, сопоставить разные позиции и собрать связный обзор. Простого списка ссылок недостаточно.

## Как использовать Искру

Сотрудник передаёт Искре тему и границы исследования, доступные публикации, критерии качества источников и шаблон обзора. Результат работы:

- Реестр источников с краткими выводами.
- Группировка по подтемам и позициям.
- Противоречия и ограничения доказательств.
- Проект аналитической записки или презентации.

Сотрудник проверяет результат и принимает окончательное решение. Эксперт проверяет источники и утверждает выводы. Подборка не служит медицинским, юридическим или иным профессиональным заключением по конкретному человеку.

**Пример задачи:** «Подготовь обзор по теме за указанный период. Сопоставь позиции источников, отдели наблюдения от причинных выводов и сделай выводы с проверяемыми ссылками».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Обзоров за год | 12 |
| Единица работы | один тематический обзор |
| Ручная работа на единицу | 600 мин |
| Работа с Искрой, включая проверку | 60 мин |
| Экономия на единицу | **540 мин** |

**12 × (600 − 60) / 60 ≈ 108 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
