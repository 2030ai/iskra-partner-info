# Кейс 38. Уведомление об изменении бюджета → обновлённая форма сметы

**Расчётный потенциал: ≈12 часов в год при указанном ниже объёме работы.**

**Пользователь:** бухгалтерия, финансовая служба, бюджетная организация.

## Какая работа занимает время

Из каждого уведомления нужно перенести суммы в нужные разделы сметы, пересчитать итог и проверить соответствие формы. Операция короткая, но регулярно повторяется.

## Как использовать Искру

Сотрудник передаёт Искре уведомления, действующую смету, правила соответствия кодов и утверждённую форму. Результат работы:

- Проект изменения сметы по форме.
- Разноска сумм по заданным кодам.
- Контрольные итоги и сверка с уведомлением.
- Список строк, требующих ручной проверки.

Сотрудник проверяет результат и принимает окончательное решение. Бухгалтер проверяет и утверждает форму. Запись в учётную систему и изменение утверждённого бюджета выполняются по действующему порядку.

**Пример задачи:** «Подготовь изменения сметы по уведомлениям и образцу. Сверь коды и суммы, покажи контрольные итоги. Несопоставленные строки вынеси на проверку».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Уведомлений в месяц | 20 |
| Месяцев | 12 |
| Единица работы | одно уведомление |
| Ручная работа на единицу | 5 мин |
| Работа с Искрой, включая проверку | 2 мин |
| Экономия на единицу | **3 мин** |

**20 × 12 × (5 − 2) / 60 ≈ 12 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
