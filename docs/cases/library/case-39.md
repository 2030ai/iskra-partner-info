# Кейс 39. Табель и штатное расписание → кадровый дашборд

**Расчётный потенциал: ≈480 часов в год при указанном ниже объёме работы.**

**Пользователь:** кадровая служба, руководитель подразделения.

## Какая работа занимает время

Явка, отсутствия и вакансии находятся в разных таблицах. Сотрудник вручную расшифровывает условные обозначения, сверяет штат и собирает несколько сводок для руководства.

## Как использовать Искру

Сотрудник передаёт Искре табель, штатное расписание, справочник условных обозначений и правила доступа. Результат работы:

- Сводка присутствия и отсутствий.
- Укомплектованность подразделений и вакансии.
- Динамика показателей и контрольные суммы.
- Дашборд и список неоднозначных записей.

Сотрудник проверяет результат и принимает окончательное решение. Кадровая служба проверяет итог. Аналитика не используется как автоматическое решение о сотруднике; получение свежего табеля из кадровой системы требует подключения.

**Пример задачи:** «Собери кадровый дашборд из табеля и штатного расписания. Условные обозначения трактуй по справочнику, сверь итоги и выдели строки, которые нельзя сопоставить однозначно».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Рабочих недель | 48 |
| Единица работы | недельный комплект кадровой аналитики |
| Ручная работа на единицу | 720 мин |
| Работа с Искрой, включая проверку | 120 мин |
| Экономия на единицу | **600 мин** |

**48 × (720 − 120) / 60 ≈ 480 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
