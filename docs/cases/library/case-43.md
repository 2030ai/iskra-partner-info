# Кейс 43. Список участников → комплект приглашений и реестр отправки

**Расчётный потенциал: ≈120 часов в год при указанном ниже объёме работы.**

**Пользователь:** организатор мероприятий, секретариат, служба протокола.

## Какая работа занимает время

Списки участников поступают из разных подразделений. Их нужно объединить, убрать дубли, проверить обращения, заполнить приглашения и подготовить файлы к отправке.

## Как использовать Искру

Сотрудник передаёт Искре списки участников, категории адресатов, проверенные контакты и шаблоны приглашений. Результат работы:

- Единый список участников с кандидатами в дубли.
- Персонализированные проекты приглашений.
- Комплект файлов по категориям.
- Реестр для проверки контактов и учёта отправки.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник проверяет адресатов и утверждает рассылку. Подготовка списка включена в расчёт пакета и отдельно не суммируется.

**Пример задачи:** «Объедини списки участников, покажи возможные дубли и подготовь приглашения по шаблонам. Сформируй реестр файлов и адресатов для проверки перед отправкой».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Мероприятий за год | 4 |
| Приглашений на мероприятие | 200 |
| Единица работы | одно приглашение, включая долю подготовки списка |
| Ручная работа на единицу | 11 мин |
| Работа с Искрой, включая проверку | 2 мин |
| Экономия на единицу | **9 мин** |

**4 × 200 × (11 − 2) / 60 ≈ 120 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
