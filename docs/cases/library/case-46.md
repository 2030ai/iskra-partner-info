# Кейс 46. Коммуникационная задача → медиаплан и проекты материалов

**Расчётный потенциал: ≈72 часов в год при указанном ниже объёме работы.**

**Пользователь:** пресс-служба, маркетинг, внутренние коммуникации.

## Какая работа занимает время

При запуске темы команда вручную согласует аудитории, сообщения, площадки, форматы и календарь. Из-за разрозненных таблиц легко пропустить зависимость или повторить одну идею в нескольких каналах.

## Как использовать Искру

Сотрудник передаёт Искре цель, аудитории, согласованные факты, список каналов, календарь и ограничения ресурсов. Результат работы:

- Медиаплан по датам, каналам и аудиториям.
- Ключевые сообщения и форматы материалов.
- Проекты кратких заданий авторам.
- Показатели результата и вопросы для согласования.

Сотрудник проверяет результат и принимает окончательное решение. Команда утверждает сообщения, бюджеты и публикации. Планирование не гарантирует охват или конверсию; их измеряют отдельно.

**Пример задачи:** «Собери медиаплан по брифу: аудитория, сообщение, канал, дата, формат и ответственный. Покажи зависимости и подготовь краткие задания на материалы».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Медиапланов за год | 12 |
| Единица работы | один медиаплан |
| Ручная работа на единицу | 480 мин |
| Работа с Искрой, включая проверку | 120 мин |
| Экономия на единицу | **360 мин** |

**12 × (480 − 120) / 60 ≈ 72 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
