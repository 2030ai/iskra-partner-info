# Кейс 18. Таблицы и справки → управленческий доклад с графиками

**Расчётный потенциал: ≈168 часов в год при указанном ниже объёме работы.**

**Пользователь:** аналитик, экономист, руководитель подразделения.

## Какая работа занимает время

Очередной доклад собирается из тех же типов таблиц: нужно извлечь показатели, сверить периоды, построить графики, написать выводы и оформить слайды. При каждой правке цифры приходится обновлять в нескольких файлах.

## Как использовать Искру

Сотрудник передаёт Искре таблицы и справки за сопоставимые периоды, определения показателей и шаблон доклада. Результат работы:

- Сводка ключевых показателей с контрольными расчётами.
- Графики и таблицы сравнения периодов.
- Проект доклада и презентации из одного набора данных.
- Список аномалий и ограничений исходной информации.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник проверяет факты и утверждает выводы. Время ожидания сведений от подразделений в трудозатраты не включается; 16 часов должны подтверждаться именно активной работой. В здравоохранении этот же процесс применяется к квартальному докладу об организации помощи при дорожных происшествиях: сопоставляются отчёты служб и статистика, готовятся согласованные доклад и слайды.

**Пример задачи:** «Подготовь доклад и слайды по шаблону. Сверь единицы измерения и периоды, покажи динамику и источники показателей. Отдели наблюдения от предположений о причинах».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Докладов за год | 12 |
| Единица работы | один комплект |
| Ручная работа на единицу | 960 мин |
| Работа с Искрой, включая проверку | 120 мин |
| Экономия на единицу | **840 мин** |

**12 × (960 − 120) / 60 ≈ 168 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
