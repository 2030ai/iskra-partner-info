# Кейс 11. Комплект документов → проверка полноты и запрос уточнений

**Расчётный потенциал: ≈11 000 часов в год при указанном ниже объёме работы.**

**Пользователь:** канцелярия, клиентский сервис, техническое присоединение.

## Какая работа занимает время

Входящая заявка сопровождается файлами с повторяющимися реквизитами. Сотрудник проверяет обязательные приложения, сопоставляет сведения и готовит запрос недостающих материалов.

## Как использовать Искру

Сотрудник передаёт Искре заявку с приложениями, утверждённый чек-лист, при необходимости выгрузку реестра и шаблон ответа. Результат работы:

- Карточка проверки и таблица комплектности.
- Расхождения между документами со ссылками на страницы.
- Кандидаты в повторные заявки по переданному реестру.
- Проект запроса недостающих документов и уточнений.

Сотрудник проверяет результат и принимает окончательное решение. Для электросетевой компании применяется тот же процесс к заявке на присоединение: сверяются мощность, сведения об участке и комплектность. Правомерность заявки и технические условия определяет специалист. Отраслевой вариант не прибавляется к общей экономии как отдельная операция.

**Пример задачи:** «Проверь комплект по чек-листу. Для каждого пункта укажи файл и страницу. Сверь реквизиты, покажи возможные повторы в реестре и подготовь проект письма заявителю».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Подходящих комплектов в день по всей организации | 200 |
| Рабочих дней | 220 |
| Единица работы | один комплект |
| Ручная работа на единицу | 25 мин |
| Работа с Искрой, включая проверку | 10 мин |
| Экономия на единицу | **15 мин** |

**200 × 220 × (25 − 10) / 60 ≈ 11 000 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
