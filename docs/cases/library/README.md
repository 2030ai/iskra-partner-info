# Библиотека кейсов Искры

58 сценариев для первого разговора с клиентом, выбора пилота и подготовки
демонстрации. В каждой карточке: пользователь, задача, входные материалы,
ожидаемый результат, пример запроса, ограничения и модель экономии времени.

Это сценарии применения, а не подтверждённые истории внедрений. Часы экономии
— расчётные гипотезы: замените объём и время на измерения клиента, включите
подготовку данных и проверку результата, отдельно учтите затраты на запуск.
Не суммируйте эффект карточек с пересекающимися операциями.

## Как использовать

1. Выберите задачу и ответственного за результат со стороны клиента.
2. Подготовьте разрешённую контрольную выборку и согласованные правила проверки.
3. Адаптируйте пример запроса; проверьте качество результата и полное время работы.
4. Перенесите проверяемые критерии в [карточку PoV](../../playbooks/pov-and-acceptance.md).

Работа с файлами, OCR, подключениями и расписанием зависит от доступных
[возможностей Искры](../../capabilities/index.md), прав и настроек контура.
Карточка не означает наличия готового отраслевого подключения. Отправку,
изменение данных и юридически значимые решения подтверждает уполномоченный
сотрудник. Условия обработки данных проверяются по разделу
[«Ограничения и условия»](../../legal/claims-and-limitations.md).
