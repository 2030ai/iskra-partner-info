# Кейс 51. Заявление по земельному участку → предварительная проверка комплекта

**Расчётный потенциал: ≈250 часов в год при указанном ниже объёме работы.**

**Пользователь:** служба имущества, земельный отдел, девелопер.

## Какая работа занимает время

Заявление сопровождают схемы и документы с повторяющимися сведениями. Специалист вручную проверяет комплектность, реквизиты и соответствие заявленной процедуре, затем составляет запрос уточнений.

## Как использовать Искру

Сотрудник передаёт Искре заявление, приложения, актуальный перечень требований и шаблон запроса уточнений. Результат работы:

- Карточка заявления и комплектность.
- Расхождения в реквизитах и описании участка.
- Ссылки на документы, требующие уточнения.
- Проект запроса недостающих сведений.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник подтверждает замечания и решение. Проверка геометрии, пересечений, ограничений использования и сведений специализированных реестров требует отдельного решения.

**Пример задачи:** «Проверь комплект по приложенному регламенту: документы, реквизиты, основания обращения. Покажи источники замечаний и подготовь проект запроса уточнений».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Комплектов за год | 600 |
| Единица работы | одна предварительная документальная проверка |
| Ручная работа на единицу | 40 мин |
| Работа с Искрой, включая проверку | 15 мин |
| Экономия на единицу | **25 мин** |

**600 × (40 − 15) / 60 ≈ 250 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
