# Кейс 24. Разрозненная статистика → исследование транспортных потоков

**Расчётный потенциал: ≈420 часов в год при указанном ниже объёме работы.**

**Пользователь:** территориальный аналитик, логистическая служба, девелопер.

## Какая работа занимает время

Для оценки потоков и инфраструктурных ограничений аналитик собирает данные из нескольких источников, сверяет несовпадающие оценки, строит графики и оформляет исследование для руководства.

## Как использовать Искру

Сотрудник передаёт Искре доступную статистику потоков, методики подсчёта, карты или таблицы направлений и перечень вопросов. Результат работы:

- Сводная таблица показателей с периодами и происхождением.
- Карта расхождений между источниками.
- Графики потоков и сценарные расчёты с явными допущениями.
- Проект аналитического отчёта или дашборда.

Сотрудник проверяет результат и принимает окончательное решение. Специалист утверждает методику и выводы. Реальные датчики, транспортные системы и оперативные потоки данных подключаются отдельным проектом.

**Пример задачи:** «Собери исследование по предоставленным данным. Раздели измеренные показатели и модельные оценки, покажи расхождения источников и подготовь сценарии нагрузки».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Исследований за год | 12 |
| Единица работы | одно исследование |
| Ручная работа на единицу | 2 400 мин |
| Работа с Искрой, включая проверку | 300 мин |
| Экономия на единицу | **2 100 мин** |

**12 × (2 400 − 300) / 60 ≈ 420 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
