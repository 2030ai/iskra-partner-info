# Кейс 58. Пакет сканов → список страниц для повторной проверки

**Расчётный потенциал: ≈33,3 часа в год при указанном ниже объёме работы.**

**Пользователь:** архив, служба оцифровки, документооборот.

## Какая работа занимает время

Контролёр просматривает сканы, отмечает нечитаемые страницы, перекосы и неполные изображения, затем составляет список пересканирования. При больших пакетах ручная проверка становится узким местом.

## Как использовать Искру

Сотрудник передаёт Искре небольшие партии сканов, эталоны качества, перечень ожидаемых страниц и правила контроля. Результат работы:

- Кандидаты в нечитаемые или неполные страницы.
- Сопоставление с перечнем ожидаемых страниц.
- Реестр замечаний с фрагментами для контролёра.
- Проект задания на пересканирование.

Сотрудник проверяет результат и принимает окончательное решение. Нужен отдельный сценарий пакетной обработки и проверка обнаружения дефектов на размеченной выборке. Контролёр утверждает пересканирование; автоматическая приёмка всего архива не обещается.

**Пример задачи:** «Проверь тестовый пакет по критериям качества. Покажи страницы, которые требуют внимания, с примерами дефектов. Подготовь реестр для подтверждения контролёром».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Страниц в пилотном годовом потоке | 1 000 |
| Единица работы | одна страница, включая проверку результата |
| Ручная работа на единицу | 4 мин |
| Работа с Искрой, включая проверку | 2 мин |
| Экономия на единицу | **2 мин** |

**1 000 × (4 − 2) / 60 ≈ 33,3 часа в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
