# Кейс 10. Наградной или кадровый пакет → проверка полноты и ходатайство

**Расчётный потенциал: ≈85 часов в год при указанном ниже объёме работы.**

**Пользователь:** кадровая служба, секретариат комиссии, служба поощрений.

## Какая работа занимает время

Пакет собирается из сканов, справок, выписок и ходатайств. Сотрудник сверяет одни и те же сведения, проверяет комплектность и историю представлений, затем готовит итоговое письмо.

## Как использовать Искру

Сотрудник передаёт Искре комплект документов, актуальный перечень требований, разрешённую выгрузку истории и шаблон ходатайства. Результат работы:

- Таблица комплектности по требованиям.
- Расхождения в датах, стаже и реквизитах.
- Возможные повторные представления по загруженному реестру.
- Проект ходатайства и перечень уточнений.

Сотрудник проверяет результат и принимает окончательное решение. Решение о представлении принимает комиссия или ответственное лицо. Доступ к кадровым данным задаётся правами рабочей папки.

**Пример задачи:** «Проверь комплект по перечню требований и сверь сведения между файлами. Укажи источники замечаний, проверь повторы по реестру и подготовь проект ходатайства».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Пакетов за год | 20 |
| Единица работы | один пакет |
| Ручная работа на единицу | 300 мин |
| Работа с Искрой, включая проверку | 45 мин |
| Экономия на единицу | **255 мин** |

**20 × (300 − 45) / 60 ≈ 85 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
