# Кейс 29. Тарифные формы → сверка расходов и баланса ресурсов

**Расчётный потенциал: ≈72 часов в год при указанном ниже объёме работы.**

**Пользователь:** тарифная служба, ресурсоснабжающая организация, экономический отдел.

## Какая работа занимает время

К рассмотрению тарифов нужно сопоставить плановые и фактические расходы по организациям и статьям, проверить балансы и выделить отклонения. Таблицы разных периодов имеют сложную структуру и требуют ручной сборки.

## Как использовать Искру

Сотрудник передаёт Искре выгрузки тарифных форм за сопоставимые периоды, справочники организаций и статей, правила расчёта и шаблон записки. Результат работы:

- Сопоставление плана и факта по статьям расходов.
- Проверка баланса подачи, реализации и потерь ресурса.
- Список отклонений и несопоставимых данных.
- Проект аналитической записки и дашборда.

Сотрудник проверяет результат и принимает окончательное решение. Экономист проверяет расчёты, тарифное решение принимает уполномоченный орган. Для неподдерживаемого исходного формата требуется согласованная выгрузка. Обычный финансовый план-факт с теми же данными повторно не учитывается.

**Пример задачи:** «Сверь тарифные формы по организациям, периодам и статьям. Проверь балансы и единицы измерения, покажи отклонения и подготовь записку с источниками расчётов».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Циклов за год | 4 |
| Единица работы | один цикл тарифной аналитики |
| Ручная работа на единицу | 1 200 мин |
| Работа с Искрой, включая проверку | 120 мин |
| Экономия на единицу | **1 080 мин** |

**4 × (1 200 − 120) / 60 ≈ 72 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
