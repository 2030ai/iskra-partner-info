# Кейс 57. Запрос на обучение → сравнение программ и план выбора

**Расчётный потенциал: ≈54 часов в год при указанном ниже объёме работы.**

**Пользователь:** корпоративный университет, кадровая служба, образовательный консультант.

## Какая работа занимает время

Для выбора программы нужно открыть десятки страниц, сопоставить содержание, формат, язык, сроки и требования. Условия описаны по-разному и быстро устаревают.

## Как использовать Искру

Сотрудник передаёт Искре цели обучения, профиль участников, ограничения и доступные официальные описания программ. Результат работы:

- Сравнительная таблица подходящих программ.
- Соответствие целям и ограничениям.
- Сроки, требования и недостающие сведения с источниками.
- Вопросы организаторам и проект плана выбора.

Сотрудник проверяет результат и принимает окончательное решение. Заказчик подтверждает актуальность условий и выбирает программу. Искра готовит материалы для решения, а не гарантирует поступление или результат обучения.

**Пример задачи:** «Сравни программы по нашим целям и ограничениям. Используй официальные описания, укажи даты и источники, выдели неизвестные условия и вопросы организаторам».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Подборок за год | 12 |
| Единица работы | одна подборка |
| Ручная работа на единицу | 360 мин |
| Работа с Искрой, включая проверку | 90 мин |
| Экономия на единицу | **270 мин** |

**12 × (360 − 90) / 60 ≈ 54 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
