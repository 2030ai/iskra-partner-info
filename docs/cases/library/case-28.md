# Кейс 28. Прогноз и факт → оценка точности и проверка поправок

**Расчётный потенциал: ≈76 часов в год при указанном ниже объёме работы.**

**Пользователь:** экономический отдел, планирование, производственная аналитика.

## Какая работа занимает время

Подразделения присылают прогнозы и фактические результаты в разных файлах. Аналитик сопоставляет периоды, ищет систематические отклонения и проверяет, помогает ли корректировка повысить точность.

## Как использовать Искру

Сотрудник передаёт Искре историю прогнозов и фактов, идентификаторы подразделений, определения показателей и согласованный порог отклонения. Результат работы:

- Единая таблица прогнозов и фактов по периодам.
- Рейтинг ошибок и систематических смещений.
- Предлагаемые поправки с проверкой на отложенном периоде.
- Отчёт о том, улучшилась ли точность после корректировки.

Сотрудник проверяет результат и принимает окончательное решение. Аналитик утверждает методику и применение поправок. Обычная сверка исполнения плана — другой этап; при использовании общей подготовки данных она учитывается один раз.

**Пример задачи:** «Сопоставь прогнозы и факты по периодам. Найди систематические ошибки и предложи поправки. Проверь их на периоде, который не использовался для расчёта поправок, и покажи результат».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Циклов за год | 12 |
| Единица работы | один цикл проверки прогнозов |
| Ручная работа на единицу | 390 мин |
| Работа с Искрой, включая проверку | 10 мин |
| Экономия на единицу | **380 мин** |

**12 × (390 − 10) / 60 ≈ 76 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
