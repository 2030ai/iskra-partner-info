# Кейс 36. Версии соглашения → изменения обязательств и пояснительная записка

**Расчётный потенциал: ≈60 часов в год при указанном ниже объёме работы.**

**Пользователь:** юрист, финансовая служба, договорной отдел.

## Какая работа занимает время

Несколько дополнительных соглашений меняют сроки, суммы и формулировки. Сотруднику нужно восстановить действующую редакцию, найти отличия очередного проекта и объяснить их руководителю.

## Как использовать Искру

Сотрудник передаёт Искре основной договор, дополнительные соглашения, проект новой версии и шаблон записки. Результат работы:

- Хронология версий с их статусами.
- Таблица изменений сроков, сумм и обязательств.
- Разделение подписанных условий и проекта.
- Проект пояснительной записки для согласования.

Сотрудник проверяет результат и принимает окончательное решение. Юрист утверждает трактовку обязательств. Рассмотрение и подписание соглашения остаются за ответственными лицами.

**Пример задачи:** «Сравни версии соглашения. Покажи, что действует сейчас и что меняет новый проект. Для каждого изменения укажи документ и пункт, подготовь записку руководителю».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Пакетов версий за год | 5 |
| Единица работы | один пакет версий |
| Ручная работа на единицу | 780 мин |
| Работа с Искрой, включая проверку | 60 мин |
| Экономия на единицу | **720 мин** |

**5 × (780 − 60) / 60 ≈ 60 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
