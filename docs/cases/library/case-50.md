# Кейс 50. Технологические тренды → предложения для портфеля проектов

**Расчётный потенциал: ≈168 часов в год при указанном ниже объёме работы.**

**Пользователь:** цифровизация, инновации, стратегическое развитие.

## Какая работа занимает время

Команда следит за технологиями и одновременно ведёт портфель проектов. Чтобы предложить полезное изменение, нужно сопоставить внешние примеры с текущими целями, мероприятиями и ограничениями организации.

## Как использовать Искру

Сотрудник передаёт Искре доступные публикации о технологиях, актуальный реестр проектов, цели и критерии применимости. Результат работы:

- Короткая сводка релевантных технологических изменений.
- Связь каждого изменения с конкретными проектами и целями.
- Пробелы и варианты инициатив с обоснованиями.
- Проект записки для обсуждения руководством.

Сотрудник проверяет результат и принимает окончательное решение. Руководство оценивает применимость и утверждает инициативы. Сбор новостей, если он уже включён в дайджест, повторно в экономии не учитывается.

**Пример задачи:** «Сопоставь технологические изменения с нашим портфелем. Покажи, какие проекты они затрагивают, предложи варианты действий и укажи источники и ограничения каждого предложения».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Выпусков за год | 48 |
| Единица работы | одна справка с предложениями |
| Ручная работа на единицу | 240 мин |
| Работа с Искрой, включая проверку | 30 мин |
| Экономия на единицу | **210 мин** |

**48 × (240 − 30) / 60 ≈ 168 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
