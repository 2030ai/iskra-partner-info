# Кейс 42. Календарь событий → персонализированные поздравления и приветствия

**Расчётный потенциал: ≈166,7 часа в год при указанном ниже объёме работы.**

**Пользователь:** секретариат, протокольная служба, пресс-служба.

## Какая работа занимает время

Для каждого адресата нужно найти сведения, подобрать обращение и тон, написать текст, проверить повторы и оформить документ. При массовой подготовке повторяются десятки одинаковых действий.

## Как использовать Искру

Сотрудник передаёт Искре проверенный календарь, разрешённый список адресатов, образцы прошлых текстов и требования к оформлению. Результат работы:

- Проекты поздравлений под категории адресатов.
- Проверка обращений, дат и объёма.
- Варианты формулировок без буквальных повторов образцов.
- Комплект файлов и реестр для согласования.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник утверждает содержание и отправку. Рассылка и работа с календарём подключаются по потребности; подпись руководителя не имитируется.

**Пример задачи:** «Подготовь поздравления по списку и образцам. Сохрани факты из базы, проверь обращения и даты. Варианты текстов и реестр файлов передай на согласование».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Текстов за год | 200 |
| Единица работы | один текст с оформлением |
| Ручная работа на единицу | 60 мин |
| Работа с Искрой, включая проверку | 10 мин |
| Экономия на единицу | **50 мин** |

**200 × (60 − 10) / 60 ≈ 166,7 часа в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
