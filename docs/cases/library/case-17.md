# Кейс 17. Отчёты подразделений → единый свод для руководства

**Расчётный потенциал: ≈360 часов в год при указанном ниже объёме работы.**

**Пользователь:** штаб мероприятий, управляющая компания, распределённая организация.

## Какая работа занимает время

Подразделения присылают сведения в разных форматах. Два сотрудника вручную приводят их к одной форме, убирают дубли, считают итоги и готовят общий отчёт.

## Как использовать Искру

Сотрудник передаёт Искре отчёты подразделений, единый шаблон, перечень ожидаемых участников и правила подсчёта. Результат работы:

- Общая таблица с едиными полями.
- Список дублей, пропусков и противоречий.
- Итоги по подразделениям и категориям.
- Проект сводного отчёта и короткой презентации.

Сотрудник проверяет результат и принимает окончательное решение. Ответственный сотрудник проверяет контрольные суммы и утверждает свод. Если доклад и презентация построены на этом же своде, их экономия повторно не учитывается.

**Пример задачи:** «Сведи отчёты по шаблону, сохрани ссылки на источники строк. Покажи отсутствующие подразделения и противоречия. Подготовь итоговый отчёт с проверяемыми суммами».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Сводов за год | 12 |
| Единица работы | один свод, суммарно на команду |
| Ручная работа на единицу | 1 920 мин |
| Работа с Искрой, включая проверку | 120 мин |
| Экономия на единицу | **1 800 мин** |

**12 × (1 920 − 120) / 60 ≈ 360 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
