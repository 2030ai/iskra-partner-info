# Кейс 27. Журнал сеанса оповещения → отчёт о доставке и недоступных адресатах

**Расчётный потенциал: ≈425,8 часа в год при указанном ниже объёме работы.**

**Пользователь:** диспетчерская, эксплуатация, служба непрерывности.

## Какая работа занимает время

После каждого сеанса оповещения сотрудник подсчитывает доставленные сообщения, разбирает недоступных адресатов и готовит справку руководству. Повторяемая отчётность отвлекает от работы с исключениями.

## Как использовать Искру

Сотрудник передаёт Искре журнал сеанса, список ожидаемых адресатов, правила статусов и шаблон отчёта. Результат работы:

- Проверенные итоги доставки по группам.
- Список недоставленных и неподтверждённых уведомлений.
- Сравнение с предыдущими сеансами.
- Проект справки и перечень адресатов для ручной проверки.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник проверяет исключения и утверждает справку. Запуск оповещения и оперативные решения в этот сценарий не входят; подключение к журналам согласуется отдельно.

**Пример задачи:** «Разбери журнал оповещения. Сверь число адресатов, статусы и контрольные суммы. Подготовь отчёт и отдельный список неподтверждённой доставки».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Сеансов в день | 2 |
| Дней работы службы | 365 |
| Единица работы | один отчёт по сеансу |
| Ручная работа на единицу | 45 мин |
| Работа с Искрой, включая проверку | 10 мин |
| Экономия на единицу | **35 мин** |

**2 × 365 × (45 − 10) / 60 ≈ 425,8 часа в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
