# Кейс 47. Документ → перевод с единым глоссарием

**Расчётный потенциал: ≈100 часов в год при указанном ниже объёме работы.**

**Пользователь:** редакторская служба, международный отдел, переводчик.

## Какая работа занимает время

Типовые документы повторяют одни и те же термины и обороты, но перевод приходится делать и сверять заново. Несогласованные формулировки создают дополнительную редакторскую работу.

## Как использовать Искру

Сотрудник передаёт Искре исходный текст, корпоративный глоссарий, утверждённые параллельные тексты и требования к стилю. Результат работы:

- Проект перевода с сохранённой структурой.
- Терминологические соответствия по глоссарию.
- Список неоднозначных фрагментов.
- Проверка единообразия повторяющихся формулировок.

Сотрудник проверяет результат и принимает окончательное решение. Переводчик утверждает результат. Для каждого языка и типа документа качество проверяется отдельно; заверенный перевод требует установленной процедуры.

**Пример задачи:** «Подготовь перевод с нашим глоссарием и образцами. Сохрани структуру и числа, вынеси неоднозначные термины на выбор переводчика».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Типовых текстов в месяц | 20 |
| Месяцев | 12 |
| Единица работы | один типовой текст согласованного объёма |
| Ручная работа на единицу | 60 мин |
| Работа с Искрой, включая проверку | 35 мин |
| Экономия на единицу | **25 мин** |

**20 × 12 × (60 − 35) / 60 ≈ 100 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
