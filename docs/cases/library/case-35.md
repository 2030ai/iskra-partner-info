# Кейс 35. Изменения правил → сводка и список затронутых документов

**Расчётный потенциал: ≈384 часа в год при указанном ниже объёме работы.**

**Пользователь:** юридический отдел, комплаенс, методологическая служба.

## Какая работа занимает время

Каждую неделю специалист просматривает изменения внешних требований, сопоставляет их с внутренними документами и готовит список необходимых обновлений. На ручной поиск уходит больше времени, чем на решение, что менять.

## Как использовать Искру

Сотрудник передаёт Искре доступные актуальные источники, перечень отслеживаемых тем и действующие документы организации. Результат работы:

- Сводка относящихся к организации изменений.
- Сопоставление изменений с внутренними документами.
- Ссылки на редакции и даты.
- Проект плана актуализации для юриста.

Сотрудник проверяет результат и принимает окончательное решение. Юрист подтверждает применимость изменений и принимает решения. Поиск в закрытой правовой системе требует разрешённого подключения; базовый вариант работает с выгрузками.

**Пример задачи:** «Сопоставь изменения из источников с нашими документами. Укажи затронутые пункты, редакции и сроки из источника. Подготовь перечень вопросов и план актуализации».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Еженедельных обзоров | 48 |
| Единица работы | один обзор |
| Ручная работа на единицу | 600 мин |
| Работа с Искрой, включая проверку | 120 мин |
| Экономия на единицу | **480 мин** |

**48 × (600 − 120) / 60 ≈ 384 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
