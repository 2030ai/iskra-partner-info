# Кейс 6. Табличная выгрузка → комплект типовых документов

**Расчётный потенциал: ≈1 400 часов в год при указанном ниже объёме работы.**

**Пользователь:** канцелярия, надзорная служба, операционный бэк-офис.

## Какая работа занимает время

По одной записи нужно подготовить несколько документов с одинаковыми реквизитами. Сотрудник переносит данные в каждый шаблон, проверяет согласованность и сохраняет файлы по отдельности.

## Как использовать Искру

Сотрудник передаёт Искре проверенную выгрузку записей, утверждённые шаблоны и правила заполнения. Результат работы:

- Комплект проектов документов на каждую запись.
- Единые реквизиты во всех формах.
- Реестр созданных файлов и пропущенных записей.
- Список ошибок исходных данных до подписания.

Сотрудник проверяет результат и принимает окончательное решение. Официальные решения, подпись и выпуск документов остаются за уполномоченным сотрудником. Подключение реальной выгрузки и согласование шаблонов — часть настройки.

**Пример задачи:** «По выгрузке сформируй комплекты по трём шаблонам. Сверь общие поля между документами и подготовь реестр результатов. Записи с недостающими реквизитами вынеси отдельно».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Комплектов в месяц | 1 000 |
| Месяцев | 12 |
| Единица работы | один комплект |
| Ручная работа на единицу | 10 мин |
| Работа с Искрой, включая проверку | 3 мин |
| Экономия на единицу | **7 мин** |

**1 000 × 12 × (10 − 3) / 60 ≈ 1 400 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
