# Кейс 15. Реестр заявок → просрочки и список действий на сегодня

**Расчётный потенциал: ≈183,3 часов в год при указанном ниже объёме работы.**

**Пользователь:** операционная служба, клиентский сервис, руководитель подразделения.

## Какая работа занимает время

Каждое утро специалист просматривает выгрузку заявок, ищет просроченные и приближающиеся сроки, выясняет исполнителя и собирает сообщение для команды.

## Как использовать Искру

Сотрудник передаёт Искре актуальную выгрузку заявок, правила сроков, статусы и справочник исполнителей. Результат работы:

- Список просроченных и ближайших к сроку заявок.
- Группировка по исполнителям и типам услуг.
- Сводка изменений по сравнению с прошлым днём.
- Проекты адресных напоминаний.

Сотрудник проверяет результат и принимает окончательное решение. Начать можно с ручной выгрузки. Получение свежих данных и доставка напоминаний по расписанию требуют доступных подключений и согласованного порядка отправки.

**Пример задачи:** «Разбери реестр на сегодняшнюю дату. Покажи просрочки и ближайшие сроки, сгруппируй по исполнителям и подготовь короткую сводку с действиями по каждому делу».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Рабочих дней | 220 |
| Единица работы | одна дневная сводка |
| Ручная работа на единицу | 60 мин |
| Работа с Искрой, включая проверку | 10 мин |
| Экономия на единицу | **50 мин** |

**220 × (60 − 10) / 60 ≈ 183,3 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
