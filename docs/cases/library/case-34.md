# Кейс 34. Ведомость объёмов работ → дефектная ведомость по форме

**Расчётный потенциал: ≈175 часов в год при указанном ниже объёме работы.**

**Пользователь:** строительный заказчик, инженерная служба, эксплуатация.

## Какая работа занимает время

Инженер вручную переносит позиции из проектной ведомости в утверждённую форму, проверяет единицы, разделы и оформление. На каждом объекте повторяется одинаковая работа с таблицами.

## Как использовать Искру

Сотрудник передаёт Искре ведомость объёмов работ, утверждённую форму дефектной ведомости и правила переноса. Результат работы:

- Проект дефектной ведомости в требуемой структуре.
- Связь каждой позиции с исходной ведомостью.
- Проверка единиц, количеств и группировки работ.
- Список неоднозначных соответствий для инженера.

Сотрудник проверяет результат и принимает окончательное решение. Инженер проверяет и утверждает документ. Сценарий переносит данные проектной документации; фактическое обследование объекта и установление дефектов им не заменяются.

**Пример задачи:** «Собери дефектную ведомость строго по образцу из приложенной ВОР. Сохрани единицы и объёмы, покажи источник каждой позиции и выдели неоднозначные соответствия».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Ведомостей за год | 25 |
| Единица работы | одна ведомость |
| Ручная работа на единицу | 480 мин |
| Работа с Искрой, включая проверку | 60 мин |
| Экономия на единицу | **420 мин** |

**25 × (480 − 60) / 60 ≈ 175 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
