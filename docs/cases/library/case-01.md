# Кейс 1. Обращение → карточка регистрации и уведомление

**Расчётный потенциал: ≈1 300 часов в год при указанном ниже объёме работы.**

**Пользователь:** приёмная, клиентский сервис, канцелярия.

## Какая работа занимает время

Каждое входящее обращение начинается с одинаковой работы: найти контакты и суть запроса, перенести сведения в журнал, присвоить тему и подготовить подтверждение получения. При большом потоке ручной ввод занимает сотни часов.

## Как использовать Искру

Сотрудник передаёт Искре тексты обращений или читаемые сканы, форму карточки, справочник тематик и шаблон уведомления. Результат работы:

- Карточка с извлечёнными реквизитами и краткой сутью обращения.
- Строка для загрузки в журнал регистрации.
- Проект уведомления о получении.
- Перечень полей, которые требуют уточнения.

Сотрудник проверяет результат и принимает окончательное решение. Время рассмотрения сути обращения сюда не входит. Присвоение официального номера и запись в систему делопроизводства выполняются сотрудником либо через отдельно настроенное подключение.

**Пример задачи:** «Собери карточки по приложенной форме. Для каждого реквизита укажи фрагмент-источник. Пропуски вынеси в список уточнений. Подготовь проекты уведомлений».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Обращений за год | 6 000 |
| Единица работы | одно обращение |
| Ручная работа на единицу | 15 мин |
| Работа с Искрой, включая проверку | 2 мин |
| Экономия на единицу | **13 мин** |

**6 000 × (15 − 2) / 60 ≈ 1 300 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
