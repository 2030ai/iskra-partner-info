# Кейс 13. Запись совещания → протокол и перечень поручений

**Расчётный потенциал: ≈84 часов в год при указанном ниже объёме работы.**

**Пользователь:** секретарь, помощник руководителя, руководитель проекта.

## Какая работа занимает время

После встречи нужно переслушать запись, отделить решения от обсуждения, выписать ответственных и сроки, затем оформить протокол. Эта работа повторяется независимо от темы совещания.

## Как использовать Искру

Сотрудник передаёт Искре аудиозапись либо расшифровку, список участников и шаблон протокола. Результат работы:

- Краткий итог встречи и принятые решения.
- Таблица поручений с ответственными и сроками.
- Проект протокола по шаблону.
- Вопросы по неясным назначениям и датам.

Сотрудник проверяет результат и принимает окончательное решение. Сотрудник проверяет решения и утверждает протокол. При готовой расшифровке ручная база должна быть ниже: её нельзя сравнивать с полным циклом от аудио.

**Пример задачи:** «Подготовь протокол по шаблону. Отдели решения от предложений. Ответственных и сроки заполни по записи; неясные назначения вынеси в вопросы на уточнение».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Совещаний в месяц | 2 |
| Месяцев | 12 |
| Единица работы | один протокол |
| Ручная работа на единицу | 240 мин |
| Работа с Искрой, включая проверку | 30 мин |
| Экономия на единицу | **210 мин** |

**2 × 12 × (240 − 30) / 60 ≈ 84 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
