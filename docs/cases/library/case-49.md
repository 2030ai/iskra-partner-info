# Кейс 49. Раздел сайта → проверка полноты и актуальности по чек-листу

**Расчётный потенциал: ≈14 часов в год при указанном ниже объёме работы.**

**Пользователь:** владелец сайта, служба качества, инвестиционный или клиентский офис.

## Какая работа занимает время

Информация на портале меняется, ссылки устаревают, обязательные разделы заполняются неравномерно. Сотрудник вручную проходит чек-лист и готовит замечания подрядчику.

## Как использовать Искру

Сотрудник передаёт Искре доступные страницы или их выгрузку, актуальный чек-лист и требования к содержанию. Результат работы:

- Статус каждого пункта проверки с подтверждением.
- Отсутствующие материалы и подозрительные ссылки.
- Перечень устаревших дат и сведений для проверки.
- Проект задания на исправление сайта.

Сотрудник проверяет результат и принимает окончательное решение. Владелец сайта проверяет замечания и утверждает правки. Для сложных динамических страниц может потребоваться отдельный способ получения данных.

**Пример задачи:** «Проверь разделы по чек-листу. Для каждого пункта укажи страницу и подтверждение. Подготовь список замечаний и проект задания редактору сайта».

## Расчёт экономии

Плановый расчёт для пилота. Время с Искрой включает подготовку входных данных, проверку и исправления сотрудником; это гипотеза для сопоставимого качества результата, а не подтверждённая экономия конкретного клиента.

| Показатель | Допущение |
| ---| ---: |
| Сопоставимых проверок за год | 4 |
| Единица работы | одна полная проверка |
| Ручная работа на единицу | 240 мин |
| Работа с Искрой, включая проверку | 30 мин |
| Экономия на единицу | **210 мин** |

**4 × (240 − 30) / 60 ≈ 14 часов в год.**

Эффект относится к указанному объёму фактически обработанных задач после настройки. При меньшем использовании он уменьшается пропорционально; разовые затраты на запуск вычитаются отдельно.
